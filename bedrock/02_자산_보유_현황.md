## 1. 시스템 개요

사내 구성원에게 Amazon Bedrock 기반 Claude Code를 배포하며, 사용자별 API 호출 비용을 주기적으로 집계하여, 월간 예산 초과 시 자동으로 접근을 차단하는 시스템입니다.

### 2.2 DynamoDB

#### `bedrock-budget-user-costs`

| 항목 | 값 |
|------|-----|
| 파티션 키 (PK) | `month` (String) — 예: "2026-07" |
| 정렬 키 (SK) | `identity_arn` (String) |
| 빌링 모드 | On-Demand (PAY_PER_REQUEST) |
| 삭제 보호 | 미설정 |

**속성 구조:**

| 필드 | 타입 | 설명 |
|------|------|------|
| `cost` | Number | 월 누적 비용 (USD) |
| `calls` | Number | 호출 횟수 |
| `model_costs` | Map | 모델별 비용 `{ "opus-4-8": 12.5, "sonnet-4-6": 8.3 }` |
| `standard_cost` | Number | 일반 컨텍스트 비용 |
| `long_context_cost` | Number | 롱 컨텍스트 비용 |
